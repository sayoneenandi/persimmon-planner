# Persimmon Planner

A study planner, sprint tracker and portfolio built with scrum.

- `index.html`: the app source (also published as a claude.ai Artifact)
- `docs/index.html`: the standalone website served by GitHub Pages (Settings → Pages → Deploy from branch → `main` / `docs`)

Progress (ticked courses, learning log, board moves) is saved in your browser's local storage.
